# Belajar Java Dasar

Repository ini berisi latihan untuk membangun pemahaman dasar pemrograman Java sebelum mempelajari topik yang lebih lanjut.

## Materi

- Variabel dan tipe data.
- Operator matematika, perbandingan, dan boolean.
- Percabangan dan perulangan.
- Array, input pengguna, dan kontrol alur.
- Method, parameter, return value, overloading, dan recursion.

File latihan berada di folder `src/` dan masing-masing dapat dijalankan secara terpisah.

## Menjalankan

1. Instal JDK yang kompatibel dengan proyek.
2. Buka proyek di IDE Java.
3. Pilih kelas latihan dari folder `src/` lalu jalankan.

Contoh melalui terminal:

```bash
javac -d out src/HelloWorld.java
java -cp out HelloWorld
```

Tujuan repository ini adalah menjadi catatan belajar yang dapat dicoba, diubah, dan dikembangkan seiring bertambahnya pemahaman tentang Java.
